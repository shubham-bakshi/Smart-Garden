# Plant Parent

**Category:** Software-first plant-care assistant, a mature consumer app from Glority.
**Physical sensor:** No dedicated sensor evidence. Uses the phone's light sensor.

## Features

- Smart care reminders: water, fertilize, prune, propagate, repot.
- **Light Meter:** estimates light at the plant's location from the phone sensor and guides repositioning. This is not a continuous sensor beside the plant.
- Care guides, plant ID and diagnosis, history/journaling.
- Uses phone geolocation for climate-aware watering.

## Takeaways for us

- A UX and workflow benchmark (reminders, care routines, journaling, light guidance), not a hardware competitor.
- Its Light Meter shows the phone-based alternative to a dedicated light sensor. A continuous light sensor must beat a one-off phone reading to be worth the hardware.
